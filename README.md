SEO and production hosting

The production domain is https://vilasanja.com/. Each HTML page includes its own canonical URL, search and social metadata, and structured data. Keep those aligned with visible content when editing pages. Publish robots.txt and sitemap.xml at the domain root alongside the HTML files. Add new public pages to sitemap.xml; avoid invented last-modified dates.

After publishing, add the domain to Google Search Console and submit https://vilasanja.com/sitemap.xml. Check indexing and inspect the home and accommodation URLs. Business details should also match the verified Google Business Profile. Translations currently share a URL through the language switcher; separate crawlable language URLs are required before adding hreflang.

The `fonts/` directory contains the locally hosted Nunito font and Font Awesome icons with their licenses. Publish this directory with the stylesheets; typography and icons load without contacting third-party font services. Privacy settings control only optional Google Maps and Elfsight content.
